2. Convert bytes to KiB

Duration: 3 min

Computers count memory in powers of two. A kibibyte (KiB) is a group of 1,024 bytes.

Predict · a guess is fine

How many KiB is 3,072 bytes?

Choose one

To express 3,072 bytes in KiB, count the groups of 1,024.

  1. Start with 3,072 bytes.
  2. Divide by 1,024 bytes per KiB: 3,072 ÷ 1,024 = 3
  3. Write the result as 3 KiB.

Worth writing down

On paper, write the rule in your own words. Then check the key part:

Divide bytes by ___ to get KiB.

3. Convert KiB to bytes

Duration: 2 min

Recall

Without looking back: how many bytes are in 1 KiB?

Choose one

To convert 2 KiB to bytes, count the bytes in two groups of 1,024. 2 × 1,024 = 2,048, so 2 KiB = 2,048 bytes.

Worth writing down

On paper, write the rule in your own words. Then check the key part:

To get bytes from KiB, ___ by 1,024.

4. Practice

Duration: 5 min

Answer from memory. Pick how sure you are, then check. Use the quick reference only after you check.

1. How many KiB are in 5,120 bytes?

  1. KiB counts in powers of two, not tens.
  2. One KiB is 1,024 bytes, so divide.
  3. 5,120 ÷ 1,024 = ?
KiB
I am

5 KiB. Divide 5,120 ÷ 1,024 to count the groups. Check by multiplying 5 × 1,024.

2. How many bytes are in 7 KiB?

  1. KiB to bytes makes the number bigger.
  2. Multiply by 1,024.
  3. 7 × 1,024 = ?
bytes
I am

7,168 bytes. Multiply 7 × 1,024. Dividing would count groups when you already know there are seven.
