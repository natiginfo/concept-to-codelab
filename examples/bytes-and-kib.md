# Convert between bytes and KiB

**Time** · About 10 minutes\
**Goal** · Convert whole numbers of bytes and KiB in either direction.\
**Before you start** · You can multiply and divide whole numbers.

## Quick reference

| Task | Rule | Why |
| --- | --- | --- |
| [Convert bytes to KiB](#convert-bytes-to-kib) | Divide by 1,024. | Each full group of 1,024 bytes counts as 1 KiB. |
| [Convert KiB to bytes](#convert-kib-to-bytes) | Multiply by 1,024. | Each KiB contains 1,024 bytes. |

## Convert bytes to KiB

A kibibyte (KiB) is a group of 1,024 bytes. To express 3,072 bytes in KiB, count the groups of 1,024.

1. Start with 3,072 bytes.
2. Divide by 1,024 bytes per KiB. `3,072 ÷ 1,024 = 3`.
3. Write the result as **3 KiB**.

> **Worth writing down**\
> Divide bytes by 1,024 to count how many KiB they represent.

## Convert KiB to bytes

To convert 2 KiB to bytes, count the bytes in two groups of 1,024. `2 × 1,024 = 2,048`, so **2 KiB = 2,048 bytes**.

> **Worth writing down**\
> Multiply KiB by 1,024 to find the total number of bytes.

## Practice

Use the [quick reference](#quick-reference) if you need a rule. Write down the operation and the resulting unit for each conversion before reading the answers.

1. How many KiB are in 5,120 bytes?
2. How many bytes are in 7 KiB?

### Answers and feedback

1. **5 KiB.** Divide `5,120 ÷ 1,024` to count the groups. You can check by multiplying `5 × 1,024` to get 5,120 bytes.
2. **7,168 bytes.** Multiply `7 × 1,024` to count the bytes across seven groups. Dividing here would count groups when you already know there are seven.
